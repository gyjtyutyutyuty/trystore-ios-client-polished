# About this test1 reference archive

The files here are the documentation and artwork copied from the supplied `test1` project. They describe the separate 3105/SupportPatch app and are retained as reference material; the parent repository's own README, patch catalog, encrypted assets, key configuration, and support policy remain authoritative for TryStore or Apple Music.

Shared Airlift and patch-transaction behavior was ported selectively where compatible. App-specific catalogs, encrypted bundles, and keys were intentionally not replaced with test1 data.
